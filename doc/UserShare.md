## Making data visible to the CMS web visualization service
Log in to CERNBox and select a folder to share. Choose the vertical triple dot icon to access the context menu.

<img src="img/share-context-menu.png" >

Select the 'Share' action from the context popup menu.

<img src="img/share-popup.png" >


Make the folder sharable with the cms-vis-access group.

<img src="img/sharing.png" height="320" >
